# Анна Нигматуллина — персональная страница

Статический сайт для GitHub Pages. Сайт собран на основе резюме Анны Нигматуллиной и фотографии из PDF.

## Как разместить на GitHub Pages

1. Создайте новый публичный репозиторий, например `anna-nigmatullina.github.io`.
2. Загрузите **все файлы и папки** из этого архива в корень репозитория.
3. Откройте `Settings → Pages`.
4. В разделе **Build and deployment** выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/ (root)`.
6. Нажмите `Save`.
7. Через 1–3 минуты GitHub Pages выдаст адрес вида `https://ВАШ-ЛОГИН.github.io/ВАШ-РЕПОЗИТОРИЙ/`.

## Что можно поменять

- Текст — `index.html`
- Визуальный стиль — `styles.css`
- Фото — `assets/anna-nigmatullina.png`
- Контактный email и телефон находятся в `index.html`

## Примечание

В публичную страницу намеренно не вынесены дата рождения, семейное положение, желаемая зарплата и место проживания из резюме — для персонального сайта они обычно не нужны. Город в шапке указан как Казань по заданию.
